# 🛡️ SiteGuard AI - PPE Compliance Dashboard

An automated computer vision web application built with **Streamlit** and **YOLOv8** designed to monitor workplace safety gear and flag Personal Protective Equipment (PPE) compliance violations in real-time.

---

##  Features
* **Image Audit Mode**: Upload job site photos to automatically detect safety gear and violations.
* **Smart Categorization**: Instantly flags compliant equipment (Helmets, Vests, Gloves, Boots, Goggles) and highlights violations.
* **Modern UI**: Clean, responsive Streamlit dashboard with side-by-side audit comparison views and detailed detection logs.
* **Confidence Filtering**: Adjustable confidence threshold sidebar to fine-tune model accuracy.

---

##  Tech Stack
* **Python**
* **Streamlit** (UI Framework)
* **Ultralytics YOLOv8** (Object Detection Model)
* **OpenCV & Pillow** (Image Processing)
